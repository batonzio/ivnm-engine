# Speech Director Lite v1.0
Opt in on an MD track with director: lite, direction_mode: advisory, and optional scene and pace (auto, measured, natural, lively). Existing MD tracks remain byte-for-byte equivalent at plan level unless opted in. Explicit pauses and emotions override inferred defaults. Intent and emotion use transparent deterministic lexical/direction cues, not general prompt comprehension. Scene is retained as metadata; it is not interpreted as a free-form instruction. Only Kitten receives a supported inferred structured emotion. Pocket and Chatterbox retain the actor and text, using native punctuation, explicit inter-turn pauses and target WPM only to rank valid takes. No respeed or pitch shifting. Safe normalization currently covers selected unambiguous 12-hour clock expressions after time prepositions; dates, acronyms and ambiguous numerals remain unchanged and are flagged. Original text and normalized synthesis/QA text remain separate. No unsupported instructions are silently represented as executed. Existing compiler gates remain; demo only for unapproved voices. Production pipeline applies the director at prepare, passes synthesis text to worker, verifies normalized spoken script, and reports director metadata. Contract tests do not establish perceived emotion or pronunciation quality; listening test is still required.
