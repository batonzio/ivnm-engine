# Voice pipeline
Run prepare with a reviewed registry and asset directory; run synth once per engine with its own Python environment; run judge in a separate ASR/ECAPA environment. See workflow for dependencies. Three takes by default; explicit 1–10. The MD compiler still blocks unapproved categories, unsupported structured directions and wrong accents. Free-form direction is advisory only with explicit opt-in. Reference SHA256 checked in synthesis; no voice substitution. Kitten C++ built-ins are laboratory-only until approved matching assets exist. The ECAPA cosine scores are diagnostic only, including same/different speaker pairs and reference similarity, because the model is not calibrated for synthetic child/teen voices. ASR checks words, not phonetic accent. The output manifest is a lesson/slide-bound package for HyperDeko; publication_allowed always false until independent human review. Lab demo never publishable. The integration test does not change existing lessons, storage or approved matrix. No real student data in public repository.
