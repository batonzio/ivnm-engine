# IVNM Audio QA v0.1 — isolated pilot

Pocket and Chatterbox each produce three takes of two identical lines with the exact same repaired CA-A-M-01 synthetic reference. No student data. Technical gate: finite mono samples, duration proportional to words, near-silence, excessive clipping and active signal ratio. Independent local faster-whisper small.en checks transcript completeness (normalized WER, substitutions, deletions, insertions). Strict default rejects all nonzero edit distance; this may falsely reject good audio due to ASR errors. Select only passing takes, using clipping and a soft 150 WPM target as tie-breakers. No time stretching, no substitution of voices, no automatic claims about pronunciation, accent, emotions or timbre. A listening review is mandatory. A line without a passing take blocks final assembly. All attempts and reports are retained. This is an isolated pilot, not yet integrated with MD production or automated voice approval. The existing workflows are unchanged.
