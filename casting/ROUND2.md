# Casting round 2 — Chatterbox-first
VoxCPM2 remains rejected. Qwen3 VoiceDesign is used only to create fictional synthetic reference voices, not as an approved production provider. Model card: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign (Apache-2.0). Chatterbox Turbo renders new utterances from each reference. The age/accent descriptions are intentions, not verified labels. Each of the 12 categories receives two candidate references and three new utterances per candidate. The workflow uses separate Python environments for Qwen and Chatterbox, with CPU inference. No paid service, student data or real-person reference. All audio needs listening approval before filling primary/alternate slots. Pocket and Kitten remain eligible for later comparison using the same reference and script. Native emotional direction in Chatterbox Turbo is limited; do not claim free-form instruction support. No pitch shifting to fake age.
