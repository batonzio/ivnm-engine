# Three-engine comparison, Round 2

After the Chatterbox casting workflow completes, the comparison workflow automatically downloads its synthetic WAV reference artifacts (same source run, no regenerated references). Pocket and Kitten each produce the same three spoken lines per candidate, with the same inter-line 320 ms gaps and native speed. Thus the target is 24 × 3 × 3 = 216 test utterances across three engines, plus 24 original references. Every engine is assessed separately; a pleasant reference does not guarantee a pleasant cloned voice. Kitten uses the Python implementation for raw reference cloning, because its C++ wrapper requires offline reference preparation. This backend must be validated on CPU. No default voice substitution is permitted if reference conditioning fails. The approved voice matrix stays unchanged until listening review. VoxCPM2 remains rejected. No private or student materials. All jobs upload reports and successful recordings even if individual candidates fail.
