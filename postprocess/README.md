# IVNM Speech Postprocessing v1

CPU FFmpeg + existing ASR and speaker encoder. Raw WAVs are never edited. Unexpected recognized repeats cause rejection of the take; intentional repeats in the MD script are allowed. Long internal pauses are reported, not silently shortened. Partial-syllable stuttering can escape ASR, and must still be judged by listening. No destructive automatic syllable splicing. A failed take is replaced with the next acceptable existing take; exhaustion blocks the track (no unapproved voice substitution).

Edge trimming: at most 350 ms each end of near-digital silence, retaining at least 100 ms before detected activity when available. Internal pauses untouched. 55 Hz rumble filter, conditional mild spectral noise reduction only with quiet stationary boundary evidence, gentle 1.5:1 compression, per-line bounded gain (LUFS when measurable, active RMS fallback), 5 ms fades. Then repeat ASR and signal gates. Report raw/cleaned speaker cosine as a diagnostic, not an identity guarantee. Final two-pass loudnorm aims at -18 LUFS and <= -2 dBTP after MP3 encoding as well as WAV. Both generated from the same mastered PCM. Mastering blocks release if tolerance (±1.5 LU) or peak gate is not met. No respeed, no arbitrary EQ coloration, no cloud API.

Regression reuses the previously successful mixed-engine integration artifact, verifies hashes of original takes and exports the cleaned/mastered dialogue plus JSON. Full synthetic generation workflow is now manual to avoid unnecessarily repeating synthesis on postprocess-only changes. Actual existing lessons and Yandex Storage are unchanged.
